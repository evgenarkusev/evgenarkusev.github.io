# Сайт-візитка Євгена

Особиста сторінка, на якій я розповідаю, що роблю сайти під ключ, показую приклади й даю способи зв’язатися.

**Опублікована версія:** https://evgenarkusev.github.io/

## Для кого

Для людей, яким потрібен сайт: власники невеликого бізнесу, кав’ярні, студії, майстри. Їм швидко видно, хто я, що можу зробити й куди написати. Тексти на сторінці українською, до відвідувача звертаюся на «ти».

## З чого зроблено

Це одна сторінка на чистих HTML і CSS: без фреймворків, збирача й бібліотек. Розмітка лежить в `index.html`, стилі в `styles.css`, картинки в `images/`. Єдине, що підтягується ззовні, це шрифт Inter із Google Fonts і, якщо відвідувач погодився, Google Analytics.

Верстка спочатку під телефон, а від 768 px підлаштовується під планшет і комп’ютер. Хостинг: GitHub Pages, сайт оновлюється після кожного пушу в гілку `main`.

Правила, за якими я підтримую сайт (кольори, шрифт, відступи, мова), описані в [CLAUDE.md](CLAUDE.md).

## Що всередині

- Перший екран із коротким описом, кнопкою «Зв’язатися» та фото з блоком «Про мене».
- Три картки послуг: дизайн, верстка й розробка, запуск і підтримка.
- Приклади робіт: кав’ярня, студія йоги, ремонт квартир. Це поки заглушки, а не реальні проєкти.
- Контакти: Telegram, пошта й телефон.
- Кругла кнопка дзвінка в куті екрана, тільки на телефоні.
- Банер згоди на аналітику (Google Consent Mode V2): поки відвідувач не натиснув «Прийняти», скрипт Google навіть не завантажується.
- Події в Google Analytics: клік на головну кнопку, на Telegram і на пошту.
- Превью для месенджерів і соцмереж (Open Graph), іконки для вкладки й для екрана «Додому».

## Як запустити в себе

Збирати нічого не треба. Відкрий `index.html` у браузері, або запусти будь-який локальний сервер у цій папці, наприклад `python -m http.server`.
